# 检索与归属

代码路径相对于工程根目录；工具从脚本位置确定根目录。默认语料在 `../leeao-upstream/`，可以指定其他路径。

## 查找

1. 从 `knowledge/catalog.md` 或主题入口找文件。
2. 用 `python3 tools/corpus.py search --work 书名 关键词` 找行号。
3. 打开命中段落及必要前后文，排除目录重复命中。
4. 确认实际说话者、引文起止、作品类型与日期层次。
5. 写作中归属明确；严肃考据另查可靠版本和独立资料。

多个词默认逐行“任一词命中”，`--all` 为同一行全匹配。它不是跨段推理、语义检索，也不识别作者。

## 同一文件不等于同一声音

- 自序、信札、回忆：作者自述可证明“他如此自述”，不独立证明事情全然如此。
- 引文、附录回信、访问者发问：可能是他人文字；不能只看文件归在李敖目录下。
- 小说人物、梦中演说、排印问答：先判断虚构层次，不能认证为历史实录。
- 第三方评论与编者说明：不是李敖本人的语言样本。
- 档案或新闻被引用：文中引述不等于本工程已验证原件、数字和前后语境。

E05的信札后面有对方回信；E13嵌有朱光潜、原诗与译文；E10明言小说人物合成；E18的方块对谈不自动等于录音。它们是常见误归属的实际例子。

## 年代

区分成文、发表、修订、后记、合集自序和文中事件的日期。E14为1981年的短篇，E20为1973年的信札，不因收进较晚合集就变成晚期论辩。没有确切依据的日期保留未知。

## 引用与更新

证据卡的 `source` 相对于上游目录；行号从1开始，`line_end` 为包含端点。短定位词只帮助查找，不是完整引文。哈希保证核对的是同一份文件，不保证文件没有错字或史实错误。

`facts/leeao/verified.jsonl` 只有两条语料元信息。文件名沿用旧版，不是人物事实已经获证的承诺。

默认校验会发现语料与固定快照的漂移。需要新上游时，逐卡重核段落与观察，然后运行 `tools/corpus.py index`；不允许仅重建哈希就宣称证据继续有效。
