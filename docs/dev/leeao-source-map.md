## 定位约定

证据卡 `source` 相对于上游根目录；行号为1起、含两端的范围，基于UTF-8文本行。短定位词用于确认范围。日期为空不等于没有年代，而是不能用该卡的单一日期准确标记文本层次。

哈希和提交标识解决“是否同一份材料”，不解决“材料是否可靠、指控是否真实”。精确史实、引文和出版年代仍需可靠版本或独立来源。验证工具不会自动把作者断言升级为已核事实。
