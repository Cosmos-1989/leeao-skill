# v2.0 审查与定向升级

基线：本地工程 `a5cdc4d`。本轮仅修改 `leeao-skill/`，不改相邻马前卒知识库或上游语料，不自动推送远程。

## 主要发现

| 问题 | 旧版位置/表现 | 依据与修正 |
| --- | --- | --- |
| 高：公开生平可被变成生成者亲历 | 旧SKILL允许第一人称persona，禁止“未公开记忆”，却没有禁止借用已公开经历；之前作文有坐牢、禁书式自述风险 | 明确判断性的“我”与李敖本人履历分开，历史见闻须归属 |
| 高：修辞印象缺原文链条 | 旧 `literary_style.md` 用句法资源表与成文配方约束文气，无段落定位 | E01直接反对奇字和满篇对偶；改为细节照应、语义翻转、有限让步与情感节制 |
| 高：年代分类无依据 | 旧晚期入口以“祸台十书”分类代年代 | E14为1981年；E20为1973年信札。确定后期样本改用1999年电子报；未定出版日期保持未知 |
| 高：材料类别与真实性容易混合 | 小说、嵌套引语、附录回信和书中问答都可能被当李敖直接论述 | E05/E10/E13/E18分别标注声音和虚构边界 |
| 中：主题综述容易冒充重蒸馏 | 多个主题只有书单和泛泛性格词，不能回溯如何得出规则 | 区分本轮选段精读与保留的旧索引入口；不声称逐篇深读全集 |
| 中：路径及核验不可复跑 | 资源中的 `../leeao-upstream/` 未说明相对于何处；旧“verified”只有元信息 | 统一根目录代码路径与文件相对链接，增加脚本、清单与事实分类 |

## 从旧作文回收到评估

既往写作暴露的风险被放进 [案例集](../../evals/cases.json)：把忧虑骂成奴性、用未经证明的历史反事实赞美坚持、以古代名作对比现代日常聊天、因AI能给答案就贬低练习、替威尔逊材料中的议员虚构动机，以及用任意题目都可套的警句代替论证。

这些是需要防止的具体失败模式，不要求新文章逐项讲出“正确答案”，更不要求所有作文都采用正反合结构。

## 新的蒸馏链条

原文选段 → 带定位和限制的证据卡 → 按文体的可迁移手法 → 人工回归标准 → 原创校准样段。

20张卡覆盖11个正文/合集文件；索引记录133个正文/合集文件。二者不是同一覆盖率。证据卡是本轮编辑判断，没有经过外部学术审稿；来源校验只能复查路径、范围、定位词及快照，不能认证审美判断。

## 保留的限制

- 上游为第三方整理本，尚未校勘到可靠纸本；数字、异体字、断行和引文可能有误。
- 《大江大海骗了你》的统一成文/出版年没有由本轮材料确定，不补定。
- 两部长篇仅选读楔子与后记等局部，尚未建立章节层次或完整人物声口模型。
- 大量人物、政治、法律和节目材料仍是检索入口，不是本轮重蒸馏成果。
- 校准样段为维护者依据新版规则编写并自审，不是独立模型对照试验；不宣称写作风格效果已获统计验证。
- 没有完整人物事实库；没有自动安装、远程提交或同步用户其他位置的skill。

## 验证

- 本工程来源/资源校验通过：20张卡、11个抽样文件、8个评估案例；固定语料文件集合、哈希、行号和定位词无校验错误。
- 32项标准库单元测试通过，覆盖字面检索、行号/上下文、元信息排除、路径安全、漂移、离线缺语料和跨工作目录使用。

- 本地差异检查通过；上游语料和马前卒工程保持未修改。
