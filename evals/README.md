# 人工回归评估

[案例集](cases.json) 保存用户曾提出的作文、拟题和出处请求。它不是自动关键词打分器，也不是必须输出某种立场的答案表。

## 运行办法

在同一模型与上下文条件下，各选一个案例，分别用旧版和新版入口产生作品，保留完整输出及版本。初次维护可先使用 [原创校准样段](calibration.md) 检查规则能否落到正文；样段自审不能替代盲评。

不以含几个典故、反问、粗口或文言词判断“像”。对模型生成结果逐项审读，引用和事实单独核对。

## 五项标准

每项0至2分，记录至少一个具体句子作理由：

| 项目 | 0分 | 1分 | 2分 |
| --- | --- | --- | --- |
| 题意与争点 | 偷换题意或给对方虚构动机 | 回答题目但避开最强疑难 | 正面回答并处理有分量的疑难 |
| 论证尺度 | 个例推出全称、假反事实充证据 | 局部过强或样本偏 | 结论范围与证据匹配 |
| 文学组织 | 随处可套的警句和古雅词堆积 | 偶有细节但不参与推论 | 细节/词义/节奏推动意思 |
| 情感与语气 | 把困难者当笑料或全篇训斥 | 锋芒和体察失衡 | 对说法锋利，对人的损失有分寸 |
| 归属与原创 | 冒充生平、假引文、小说事实化 | 有含糊归属且已说明限制 | 事实可核、假设清楚、原创不冒充 |

总分8分以上且没有事实/身份红线，可视为该案例基本达标。总分不是风格相似度。短拟题只用题意、文学组织和归属三项，至多6分，5分为基本达标。事实查询以原文归属、来源层级、未知项是否明示为通过条件，不套作文总分。

## 红线与修订

发现虚构引文、传记冒充、无来源指控、将故事当史实，无论总分多少均退回修订。挑出最模板化或推论过强的一段重写，再重读全文，防止只换辞藻。

自动校验仅检查案例结构和工程来源。不宣称单元测试通过就表示语言有文气。
